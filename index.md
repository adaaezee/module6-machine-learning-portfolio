# Machine Learning - e-Portfolio

**Adaeze Ugochukwu** · MSc Artificial Intelligence, University of Essex Online · Machine Learning module

This e-portfolio collects the evidence of my work across the twelve units of the Machine Learning module. It contains the team project (Unit 6), my individual project (Unit 11), an annotated artefact for each unit, an evaluation of how the final project developed from the initial one, and my reflective piece.

Both projects use the same dataset: the 2019 New York City Airbnb listings (Dgomonov, 2019). Working on one problem from start to finish let me see how my methods and judgement changed as the module progressed.

AI tools were used in this module, and their use is stated where it applies. ChatGPT was used by the team during data cleaning and exploratory analysis. It was also used to review the Unit 5 Jaccard calculations. All results come from code I ran, and the analysis, decisions and reflection are my own.
