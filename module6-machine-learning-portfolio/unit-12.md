**Artefact:** Revisiting Industry 4.0, and my development plan

Unit 12 returned to the Industry 4.0 theme from [Unit 1](unit-01.md), adding digital twins, edge AI and the emergence of Industry 5.0, which puts people back at the centre of automated systems.


In [Unit 1](unit-01.md), I described Industry 4.0 in the security sector as a shift towards predictive, data-driven systems, and noted the limitations of biometric technologies identified by Achimba et al. (2025). Having completed the module, my view is more practical: these limitations are measurable, not abstract. My [Unit 11](../projects/unit-11-individual-presentation/) bias analysis showed the highest error for the smallest groups, which is exactly the risk for biometric systems that generalise poorly across diverse populations. My development plan carries this into my Computing Project:

| Area | Action |
|---|---|
| Interpretation | State what a stakeholder should do with each result |
| Validation and explainability | Use cross-validation and explainability methods such as SHAP by default |
| Fairness | Report model performance by subgroup, not only overall |
| Coding | Keep building independent coding confidence in Python and R |
| Peer learning | Contribute actively to module discussions |
